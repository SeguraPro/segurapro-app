## Como publicar no GitHub Pages

1. Crie um repositório no GitHub (ex.: `segurapro-app`).
   - Se quiser o endereço `https://SEU-USUARIO.github.io`, nomeie o repositório exatamente como `SEU-USUARIO.github.io`.
2. Envie o arquivo `index.html` (e este `README.md`) para a raiz do repositório.
3. No repositório, vá em **Settings → Pages**.
4. Em **Source**, escolha **Deploy from a branch**, branch **main**, pasta **/(root)** e clique em **Save**.
5. Em 1–2 minutos o site estará no ar em `https://SEU-USUARIO.github.io/segurapro-app/`.

## Personalização rápida

- **Textos e serviços:** edite direto no `index.html` (cada serviço é um bloco `<div class="card">`).
- **Cores:** altere as variáveis no topo do CSS (`--accent`, `--accent-2`, `--bg`).
- **Contato:** troque o e-mail no bloco `#contato` ou adicione um link de WhatsApp (`https://wa.me/55DDDNUMERO`).
